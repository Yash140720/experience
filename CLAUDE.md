# PROJECT CONTEXT

This is NOT a normal website.

This is a highly interactive, cinematic anniversary experience built using React and Framer Motion.

The goal is to create an emotional journey where the user relives a real relationship story step-by-step.

---

# EXPERIENCE PRINCIPLES

- The experience must feel personal, intimate, and immersive
- Content should NOT be shown all at once
- The user must PROGRESS through the story
- Each section should feel like a scene from a movie
- Avoid static scrolling layouts

---

# STORY STRUCTURE (MANDATORY)

The website is divided into 7 chapters:

1. The Unexpected Beginning
2. First Glimpse, First Madness
3. Loving You Even When I Couldn't Have You
4. The Darkest Phase
5. The Turning Point
6. Us Beyond Everything
7. Distance, But Never Apart

Final screen: Emotional reveal + anniversary message

---

# CHAPTER RULES

Each chapter MUST include:

- Title
- 3–5 short cinematic lines (NOT paragraphs)
- One highlighted memory
- One interaction gate (required to proceed)

---

# INTERACTION RULES

Every chapter must require user action before proceeding.

Allowed interaction types:
- Question/answer (memory-based)
- Tap to reveal
- Hold to continue
- Drag to unblur
- Choice selection
- Timed reveal

DO NOT allow passive scrolling through entire story.

---

# DESIGN PRINCIPLES

- Use dark theme (black / charcoal)
- Use soft glow accents (pink / gold)
- Use glassmorphism (blur + transparency)
- Maintain large spacing and minimal layout
- Typography should feel premium and cinematic

---

# ANIMATION GUIDELINES

- Use Framer Motion for all animations
- Prefer:
  - opacity fade
  - translate (y-axis)
  - scale (subtle)
- Avoid:
  - fast flashy transitions
  - excessive motion
- Animation duration: 0.6s – 1.2s

---

# UI BEHAVIOR

- Show one emotional moment at a time
- Avoid long paragraphs
- Use progressive reveal of text
- Keep interactions simple but meaningful
- Maintain focus on emotional flow

---

# COMPONENT ARCHITECTURE

- Use reusable components
- Keep logic separate from UI
- Avoid duplication
- Follow clean React functional component structure

---

# CODE STYLE

- React functional components only
- Tailwind CSS for styling
- Clean and readable code
- No unnecessary complexity
- Avoid inline messy logic

---

# FINAL EXPERIENCE GOAL

The user should feel:

"This is OUR story — not just a website"

It should feel like:
- a memory journey
- a personal interaction
- a cinematic emotional experience

NOT like:
- a blog
- a slideshow
- a generic romantic site
